The funniest excuse a dog gives after being caught eating the homework — one line, 80 characters:

> I didn't eat your homework, I marked it. It failed, so I filed it in my stomach.

The dog was never eating at all: it was grading. The homework failed the marking, so the dog filed it away the only place a dog files anything — its stomach. A dog who believes it did nothing wrong, in the dog's own voice, with the punch at the very end.

## Run it

```sh
python3 main.py
```

Writes the line byte-exact (no trailing newline) to `/output/entry.txt`, after a gate self-check: 1–200 characters, a single line, not only whitespace.
